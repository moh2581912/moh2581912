## 🏭 Featured Project — Production Line Optimization (PFA @ Gentherm Morocco)

Industrial performance improvement project on a sewing production line (16 Sewing + 13 PSA machines), combining simulation, scheduling algorithms and a supervision dashboard.

**Key results:**
- 📉 Overloaded production line-days reduced from **66 → 17**
- 📈 Service rate improved from **81.3% → 86.3%**

**What was built:**
- 🔁 Discrete-event simulation in **MATLAB/Simulink SimEvents** (log-normal processing time distribution)
- 📊 Excel scheduling tool using an **LPT + best-fit algorithm** with automatic lot splitting
- 🖥️ **MATLAB App Designer** supervision dashboard (heatmap synoptic view, alarm journal)
- 🔧 Corrective maintenance analysis: **Pareto, AMDEC, Ishikawa**
- 📈 TRS/OEE performance synthesis

**Technologies:** MATLAB, Simulink (SimEvents, App Designer), Excel/VBA, LaTeX

## ⚙️ Control Systems & Power Electronics Projects

### 🔩 Field-Oriented Control (FOC/SVPWM) of an Asynchronous Motor
Discrete field-oriented control design and simulation for an asynchronous motor (Rs = 4.85 Ω, Vn = 380V, fn = 50Hz), with space vector PWM.

### ⚙️ Industrial Servo Motor Control

### 🔌 Full Bridge Phase-Shifted (PSFB) Power Supply
Design and numerical analysis of a bidirectional PSFB converter for V2G/G2V charging applications.

**Technologies:** MATLAB, Simulink, Control Systems, Power Electronics

## 🤖 Predictive Maintenance & AI

### 🔍 MCSA + CNN 1D Predictive Maintenance Pipeline
Motor Current Signature Analysis combined with a 1D Convolutional Neural Network for fault detection and Remaining Useful Life estimation, based on EPRI NP-7502 guidelines.
- 18-feature extraction pipeline
- SVM / Random Forest classifiers + PyTorch 1D CNN (~1.2M parameters)
- RUL estimation using an exponential degradation model
- Interactive oscilloscope-style web dashboard (Chart.js)

**Technologies:** Python, PyTorch, Scikit-learn, MATLAB
